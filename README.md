# Network Sniffer — CodeAlpha Internship Task 1

## Description
A Python-based network packet sniffer that captures live
network traffic and displays source/destination IPs,
protocols (TCP, UDP, ICMP), ports, and payload data.

## Tools Used
- Python 3
- Scapy library

## How to Run
1. Install scapy: pip install scapy
2. Run as admin: sudo python3 sniffer.py

## What it captures
- Source and destination IP addresses
- Protocol type (TCP / UDP / ICMP)
- Source and destination ports
- Raw payload preview# CodeAlpha_NetworkSniffer
